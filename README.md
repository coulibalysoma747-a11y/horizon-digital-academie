# HORIZON DIGITAL ACADEMIE — Site Vitrine

Site vitrine présentant les projets de HORIZON DIGITAL ACADEMIE.

## Fichiers

- `index.html` — Page principale
- `styles.css` — Styles
- `script.js` — Interactions (menu mobile, animations)
- `robots.txt` — Pour Google (SEO)
- `sitemap.xml` — Plan du site (SEO)

## Comment modifier

Ouvre `index.html` avec un éditeur de texte (Notepad, VS Code, etc.) et modifie le contenu. Les textes sont en français, faciles à comprendre.

## Comment mettre en ligne (GRATUIT)

### Option 1 : Vercel (recommandé)
1. Crée un compte sur https://vercel.com (gratuit)
2. Installe Vercel CLI : `npm i -g vercel`
3. Dans le dossier du projet : `vercel`
4. Suis les instructions → ton site sera en ligne en 30 secondes

### Option 2 : Netlify (drag & drop)
1. Va sur https://app.netlify.com/drop
2. Glisse-dépose le dossier du projet
3. Ton site est en ligne instantanément

### Option 3 : GitHub Pages
1. Crée un dépôt GitHub
2. Pousse les fichiers
3. Active GitHub Pages dans les paramètres

## SEO (pour apparaître sur Google)

1. Inscris-toi sur https://search.google.com/search-console
2. Ajoute ton URL
3. Vérifie avec la balise HTML
4. Demande l'indexation
5. Attends 1-4 semaines
